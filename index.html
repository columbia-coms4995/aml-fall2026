Course details & prerequisites

Real ML systems live in messy environments: delayed feedback, data drift, business constraints. This course bridges algorithms and production, from the classic stack (linear models, trees) to the modern GenAI stack (LLMs, RAG, agents), with an emphasis on problem framing, system design, and failure analysis.

Deep learning and LLMs are the core of the course. We cover enough math for a white‑box understanding of debugging and optimization, not theoretical derivation.

What You Will Learn

  • Turn ambiguous business requirements into well-defined ML tasks
  • Understand why models fail in production
  • Build RAG systems, run supervised fine-tuning, design LLM agents
  • Feature engineering, pipelines, and error analysis with scikit-learn
  • Use AI coding assistants to ship production-ready code

Prerequisites

  • Python 3 with pandas, numpy, and pytorch
  • Linear algebra and basic probability and statistics
  • Familiarity with AI coding assistants is strongly recommended
