Course Overview

Real ML systems live in messy environments: delayed feedback, data drift, business constraints. This course bridges algorithms and production. We start with the classic stack (linear models, trees) and move to the modern GenAI stack (LLMs, RAG, agents), with an emphasis on problem framing, system design, and failure analysis.

Deep learning and LLMs are the core of the course. We cover enough math for a white-box understanding of debugging and optimization, not theoretical derivation.

What You Will Learn

  • Turn ambiguous business requirements into well-defined ML tasks
  • Understand why models fail in production
  • Build RAG systems, run supervised fine-tuning, design LLM agents
  • Feature engineering, pipelines, and error analysis with scikit-learn
  • Use AI coding assistants to ship production-ready code

Prerequisites

  • Python 3 with pandas, numpy, and pytorch
  • Linear algebra and basic probability and statistics
  • Familiarity with AI coding assistants is strongly recommended

Course Policies

Attendance & Recordings

Attendance is optional and not graded. No need to email about absences. Lectures are streamed on Zoom and recorded on a best-effort basis. If the stream or recording fails, get notes from peers; the lecture will not be repeated. Attend in person when you can.

Late Work

Up to 24 hours late with a 10% penalty. After that, graded as 0. Interview schedule, health issue, or other emergency? Email the instructor before the deadline with a brief explanation and documentation where applicable.

Missed Exams

Exams are taken in class on the scheduled dates. If illness, a family emergency, a religious observance, or a documented university obligation prevents you from attending, email the instructor before the exam begins, or within 24 hours in a true emergency. Every request needs supporting documentation.

If approved: for the midterm, either a make-up within one week or the 20% moves to the final, at the teaching staff's discretion. For the final, a make-up during the University's official exam period; no weight transfer. An unexcused absence is a 0. Interviews, travel, and other coursework do not qualify.

Regrades

Request in writing to the TAs within 1 week of grade release. A regrade is a full review, so the score may go up, down, or stay the same.

AI Policy

ChatGPT, Claude, Gemini, and similar tools are permitted on all assignments. Verify the output; broken code is graded as broken. Copying other students' work is plagiarism, and submitting code you cannot explain or debug in a review is an honor code violation.

Accessibility

Communication

Ed Discussion for all course questions. Email only for extension requests, exam absence requests, and sensitive personal matters.
